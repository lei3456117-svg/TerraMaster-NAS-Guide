二、铁威马 NAS 端部署（TOS 6 + Docker）

铁威马 F4-423 拥有 Intel N5095 四核处理器 + 硬件 AES 加密，在 TOS「Container Manager」中以 Host 模式运行 Tailscale 负载几乎为零。

Docker Compose 部署步骤：

  1. 打开 Tailscale 网页端 Settings -> Keys，生成 tskey-auth- 密钥。
  2. 进入 TOS 桌面「Container Manager」->「项目」->「新增」，配置来源选「创建 docker-compose.yml」。
  3. 粘贴以下配置并填入实际密钥：
version: "3.7"
services:
  tailscale:
    image: tailscale/tailscale:latest
    container_name: tailscale
    hostname: terramaster-nas
    network_mode: host
    privileged: true
    volumes:
      - /dev/net/tun:/dev/net/tun
      - tailscale-data:/var/lib/tailscale
    environment:
      - TS_AUTHKEY=tskey-auth-xxxxxx  # 填入实际密钥
      - TS_STATE_DIR=/var/lib/tailscale
      - TS_USERSPACE=false
    restart: unless-stopped

volumes:
  tailscale-data:

创建完成后，手动将右侧滑块拨至开启；在 Tailscale 网页端对该设备点击 ... 选择 Disable key expiry 保证永不掉线。

三、多端挂载与日常使用（Mac / Windows）

1. 两个分区的区别

  • 公共协作盘（public）：团队公用资料库，所有分配了账号的人都可以访问。
  • 个人专属私有盘（depp）：以你的用户名命名的私有空间（开启家目录后自动生成），其他普通账号根本看不见也进不去。

2. Mac 端挂载与开机静默自动挂载

  1. 按快捷键 Cmd + K，输入纯 IP 地址（公司输 smb://192.168.1.198，外网输 smb://100.87.114.20）。
  2. 身份选择「注册用户」，输入账号密码并勾选记住密码。
  3. 在弹出的列表框中，按住 Cmd 键同时勾选 depp 和 public 两个盘符。
  4. 开机自启：进入 Mac「系统设置 -> 通用 -> 登录项与扩展」，将桌面上的两个盘符和 Tailscale 一同加入「登录时打开」列表中。

3. Windows 电脑映射网络驱动器（Z: 盘）

按快捷键 Win + R 输入 \\192.168.1.198（外网输 \\100.87.114.20），输入密码后右键目标文件夹选择「映射网络驱动器」，分配盘符为 Z: 即可固定在我的电脑中。

四、安全分享给朋友或同事（零泄密与避坑方案）

特别警示（同事在公司直连延迟超高的根因）：在公司内，同事若连了「公司总 Wi-Fi」或输入了 100.87.114.20 虚拟 IP，会触发 NAT 回环失败或网段隔离，流量被迫绕行境外香港 DERP 中继（延迟 700ms 且限速 2Mbps）！
  1. 同办公室同事（强烈推荐）：让同事连工位 Newifi Wi-Fi，完全无需安装 Tailscale，直接连接物理内网 smb://192.168.1.198/public（延迟立降至 0.5ms，传输满速 110MB/s）。
  2. 异地同事单机分享（Share Machine）：Tailscale 后台点选 terramaster-nas 的 Share...，同事用自己的微软/苹果账号接收（切勿使用谷歌账号）。异地挂载 smb://100.87.114.20/public。
  3. NAS 权限隔离：在铁威马后台给朋友新建普通用户（切勿给 admin 组），在共享文件夹中只开放 public 权限，确保你的私有盘 depp 对其为「禁止访问」。
  4. 临时发大文件：在铁威马网页文件管理中右键文件选「创建分享」，微信直接发提取码，对方零安装秒下载。

五、与科学上网 / 代理软件共存调优

1. Mac 端 Clash Verge 避坑设置

  1. 打开 Clash Verge，先开启「系统代理」开关（激活系统权限）。
  2. 点击「系统代理」右侧齿轮 ⚙️，务必将「始终使用默认绕过」关闭（灰色）！
  3. 在当前绕过输入框填入 100.64.0.0/10 按回车，并确认已有 192.168.0.0/16，点击保存。

2. Mac 端 Antify 避坑

Antify 采用系统透明代理扩展，勾选软件名单时绝对不要勾选「访达（Finder）」，即可确保文件传输不受干预。

3. 公司路由器 v2rayA 放行（恢复 19ms 直连）

浏览器打开 http://192.168.1.1:2017，点击设置，在自定义分流规则中加入：

port(3478, 41641) -> direct
ip(100.64.0.0/10) -> direct

六、路由器底层技术备忘（管理员）

1. 端口转发（OpenWrt 官方原版）

在 OpenWrt「网络 -> 防火墙 -> 端口转发」中添加：外部 UDP 41641 -> 内部 192.168.1.198:41641。

2. 关于「Full Cone NAT」的辟谣

OpenWrt 官方原版（firewall4）默认没有国内定制版固件的「Full Cone NAT」独立勾选项，无需到处寻找。只要做好上述 41641 端口转发并配置好代理放行，穿透打洞即可稳定生效。

七、小白实战 8 大翻车避坑字典

序号 常见翻车现象 根本原因 10 秒秒解方案
1 桌面替身卡死转圈，Cmd+Q 无法退出 替身记录了服务器根路径，网络断开广播超时；系统禁止退出核心访达 终端运行 killall Finder 强制重启，删除假替身
2 访达连接提示「连接失败」 Mac 默认以客人匿名身份连接，NAS 出于安全策略拒绝 点击右上角「连接身份...」切换为「注册用户」并记住密码
3 输入 smb://.../home 报错无此共享 铁威马个人盘默认以用户名命名（如 depp）而非叫 home 输入纯 IP smb://192.168.1.198 在列表弹窗中选自己名字
4 重启 Mac 后 NAS 盘全掉，提示连不上 Tailscale 重启后未自启（处于 Stopped），系统登录项抢先连接 在 Tailscale 勾选 Launch on login 并在系统登录项中放行
5 在公司内网传文件极慢 / 同事直连延迟超高 ① 同事连了公司大楼 Wi-Fi 导致网段隔离；② 误用 100 虚拟 IP 触发 NAT 回环走境外香港中继 改连工位 Newifi Wi-Fi，直接连接内网物理地址 smb://192.168.1.198/public（0.5ms 秒开）
6 在路由器后台找不到 Full Cone NAT 重装的是 OpenWrt 官方原版，官方界面本来就没有第三方定制补丁 确认「网络 -> 防火墙 -> 端口转发」中有 UDP 41641 即可
7 Clash Verge 添加绕过规则被冲掉 开启了「始终使用默认绕过」，强制写死了内置规则 先开系统代理，关闭「始终使用默认绕过」，添加后保存
8 终端 ping 提示 via DERP(hkg) 延迟数百毫秒 路由器新代理全局拦截了 UDP 打洞探测包送去境外 在 v2rayA 自定义规则中加入 port(3478, 41641) -> direct
